# UIL-Chinese
A joke website based on my UIL Spelling Trainer framework made for possibly learning Chinese

## Features
- Answer the correct (or multiple correct) pinyin from the character
- Filter by pinyin alphabetics or frequency
- Remove characters from the deck after correctly identifying them after a certain number of times
- Saves options to local storage, you can start where you ended

## Usage
- Go to https://ansere.github.io/UIL-Chinese/
- Answer in pinyin with tones represented by numbers 1 to 5.
- Learn!
